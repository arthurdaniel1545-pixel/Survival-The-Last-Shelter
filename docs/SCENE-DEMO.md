# Demo scene preparation

The Unity Editor menu `Survival/Build Demo Scene` creates a skeleton scene at `Assets/Scenes/SurvivalDemo.unity`.

Manual work still required:

- Load GLB assets with glTFast.
- Place buildings, roads, vegetation and props.
- Configure colliders, NavMesh, lighting and camera.
- Connect player and enemy prefabs.
- Validate on Moto G24.

No scene has been created or tested in this repository environment.
